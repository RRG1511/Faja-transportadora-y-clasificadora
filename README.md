# Faja transportadora y clasificadora de cajas de colores
En este proyecto se diseño e implemento una maqueta funcional de un sistema que permite contabilizar la cantidad de cubos de colores que pasan por una banda transportadora y clasificarlos según su color. Este objetivo se logró mediante el uso de lógica combinacional y secuencial, que facilita el control preciso y eficiente de las operaciones de clasificación. Se construyó una banda transportadora utilizando materiales reciclados, demostrando un enfoque sostenible y económico para el desarrollo de prototipos. El resultado fue un sistema funcional que cumplió con el proceso deseado de clasificación y conteo de cubos de colores, mostrando la viabilidad y eficiencia de la automatización en tareas industriales.
